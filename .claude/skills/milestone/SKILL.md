Implement the specified milestone. Then:
1. Run the test suite and confirm all pass.
2. Confirm a clean Godot build.
3. Update the relevant system docs.
4. Stage, commit with a descriptive message, and push to GitHub.

Do not modify shared/core classes (Bitmask.cs) without asking.
