# Work Log — 2026-07-16

Godot strategy game: road/vehicle tick loop, player road placement, resources on the map, and a city consumer.

## New files (authored)

| File | What it does |
|---|---|
| `Systems/Game/Roads.cs` | Road/vehicle registry — `Dictionary<Vector2I,int>` keyed by road tile (`Build`, `IsRoad`, `AddVehicle`, `RemoveVehicle`, `VehiclesOn`, `All`). Iterating it = only road tiles, never the whole map. |
| `Systems/Game/Tick.cs` | 1/sec heartbeat. Flags roads over capacity (bottleneck) and drives the city's per-tick demand. |
| `Systems/Game/RoadPlacer.cs` | Press **R** to toggle build mode (starts off); left-click paints a rail tile on `RailroadLayer` and registers it via `Roads.Build`. |
| `Systems/Game/ResourceMap.cs` | Scatters resources on random land tiles and draws colored dots — grain yellow, iron gray, water blue, wood brown. |
| `Systems/Game/City.cs` | Capital = consumer. Demands all four resources each tick; reports what it's short on. |
| `Tests/RoadsTests.cs` | 5 unit tests for the `Roads` registry. |
